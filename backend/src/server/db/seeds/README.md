## 🚀 Використання

### 1. Запуск сидера

```bash
# Згенерувати міграції (якщо ще не зроблено)
npm run db:generate

# Застосувати міграції
npm run db:migrate

# Запустити сидер
npm run db:seed
```

### 2. Завантаження зображень

Після запуску сидера можна завантажити зображення:

```bash
npm run db:images
```

Скрипт завантажить:
- **Фото авторів** з Wikipedia (з `authorsData.pictureUrl`)
- **Обкладинки книг** з Open Library API (за ISBN або з `booksData.coverImageUrl`)

Зображення зберігаються в:
- `storage/authors/` — фото авторів
- `storage/books/` — обкладинки книг
- `storage/publishers/` — логотипи видавництв (поки не використовується)
- `storage/users/` — аватари користувачів (поки не використовується)

### 3. Перегляд даних

```bash
# Відкрити Drizzle Studio для перегляду БД
npm run db:studio
```

## 🎨 Зображення

### Автоматичне завантаження
Скрипт `download-images.ts` автоматично завантажує:
- Фото авторів з Wikipedia
- Обкладинки книг з Open Library API

### Ручне додавання
Якщо автоматичне завантаження не спрацювало, можна вручну додати зображення:

1. Покласти файл у відповідну папку (`storage/authors/`, `storage/books/` тощо)
2. Оновити запис у БД з правильним шляхом (наприклад, `/authors/shevchenko.jpg`)

### Формат шляхів
- Автори: `/authors/filename.jpg`
- Книги: `/books/filename.jpg`
- Видавництва: `/publishers/filename.jpg`
- Користувачі: `/users/filename.jpg`

## ⚠️ Важливо

- **Сидер очищає всю БД** перед вставкою даних
- Всі паролі хешуються за допомогою bcrypt
- UUID генеруються автоматично
- Дати створення/оновлення встановлюються автоматично

## 🔄 Повторний запуск

Сидер можна запускати скільки завгодно разів — він кожен раз очищає БД і вставляє свіжі дані.

```bash
npm run db:seed
```

## 🐛 Troubleshooting

### Помилка підключення до БД
Переконайтеся, що:
1. PostgreSQL запущений
2. `.env` файл містить правильний `DATABASE_URL`
3. База даних створена

### Помилка завантаження зображень
- Перевірте інтернет-з'єднання
- Деякі URL можуть бути недоступні — це нормально
- Можна вручну додати зображення пізніше

### Помилка міграцій
```bash
# Згенерувати міграції заново
npm run db:generate

# Застосувати міграції
npm run db:migrate
```
